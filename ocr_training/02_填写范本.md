# 填写范本：以下为虚构教学文本

**以下内容用于说明如何填写，不取自真实档案，不得直接填入第 58 号档案或作为历史事实。真实标注只能依据给定图像。**

假定某区域图清楚写着两行：

```text
The publick accounts were received.
£12 10s. 6d. were not paid.
```

即使 OCR 提示写成 `The public accounts were received. £72 10s. 6d. were paid.`，人工 reference 也应填原图中的两行：

```text
The publick accounts were received.
£12 10s. 6d. were not paid.
```

保留 publick 的原始拼写、£ 符号、12、not 和换行。不要因为现代英语习惯而删去 k，也不要因为账目推测改数字。

| 栏位 | 初标完成后 | 独立复核后 |
| --- | --- | --- |
| reference | 上述两行原文 | 对照图像确认或修正后的原文 |
| annotator | A01 | A01 |
| reviewer | 留空 | R02 |
| status | transcribed | approved |
| uncertainty | 无疑点则留空 | 必须为空 |
| notes | 保留历史拼写 publick | 逐字核对原图，确认金额和否定词 |

另一种情形：原图金额的首位无法分清 1 或 7。草稿可写 `£⟦不清⟧2 10s. 6d. were not paid.`，设 status=uncertain，uncertainty=`第二行金额首位无法辨认`。不要直接采用 OCR 的 72，也不要先设 approved。

## 可以直接发给历史工作者的任务说明

> 请根据包内区域图及全页图，逐字抄录原文到 annotations.csv 的 reference 栏。保留历史拼写、缩写、数字、否定词、其他语种和换行；不做现代化润色、翻译或历史补写。看不清的字符标为 ⟦不清⟧，并设 uncertain；裁切缺行或混栏设 excluded 并说明。初标完成设 transcribed，再由另一位人员对照原图复核，确认后填写不同的 reviewer 代号并设 approved。请先试标 10 个区域，统一规范后再批量处理。

`templates/annotations_blank.csv` 只有表头，供技术人员整理新的独立样本；实际试标请填写 packages 内已经关联图像和稳定 ID 的表，不自行编造行号。
