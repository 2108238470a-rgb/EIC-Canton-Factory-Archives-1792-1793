# 历史工作者标注说明

任务是“看图，忠实抄录图中实际可见的文字”，不是翻译、修辞润色、补写史实或建立人物身份。

## 每个区域怎么做

1. 打开 `images/` 中与 sample_id 对应的区域图，必要时打开 `pages/` 的全页图确认位置、行序和边缘是否被裁掉。页码是 PDF 物理页，不等同于原档页码。
2. 独立抄录到 `annotations.csv` 的 reference 栏。初稿不要先看 OCR 提示。相邻页仅帮助辨形，不能把相邻页内容抄进当前区域。
3. 保留可见历史拼写、大小写、缩写、标点、金额单位、数字及换行；不把旧拼写改成现代拼写，不展开人名缩写。
4. 一行图像文字对应一个换行。保留清楚可见的行末连字符，不自行合并断行词。无需复制视觉上的每个空格：词间一个空格，缩进不额外补空格。技术评估时应另行报告空白处理方式。
5. 改正与否以原图为准。例如字形清楚是 12，就写 12，即使账目计算看似更应为 72。姓名也不能按熟悉人物猜测。
6. 书写者的语法、词形或历史事实错误照录，疑点写 notes，不在 reference 里静默纠正。
7. 有汉字、拉丁文或其他文字就保留；不要为了“英文卷册”删掉其他语种。
8. 删改、行间插入或边注只有阅读层次明确时才整理为最终可读主文，并在 notes 描述。若不能统一确定读取层次，设为 uncertain，交复核者裁决；不要自行把多层字迹合成确定文本。
9. 有字符不清：在草稿中用 `⟦不清⟧` 标记并把 status 设为 uncertain，uncertainty 写清具体行和字符。不依据上下文补造；此类记录暂不进入普通 OCR 训练。
10. 区域图裁切不全、缺行、正文混入邻栏、错误排序、完全空白或严重不可辨认时设为 excluded，在 notes 说明，交技术人员重新裁图建包。不要直接改图或改 sample_id。

## 表格字段

| 字段 | 谁填写、填写什么 |
| --- | --- |
| sample_id / region_id / image_path / page_image_path | 系统填好，不修改 |
| volume_id / pdf_page / original_page_label | 核对来源；原档页码可补录，不能用文件名推断年代 |
| split_group | 技术负责人组织分组，同一实体卷册/相关书写者不跨集合 |
| writer_group | 确认同一书写者时填写一致代号；不确定留空，不凭文献年代推断 |
| reference | 人工逐字转录，允许单元格内换行 |
| annotator | 初标人员代号 |
| reviewer | 独立复核人员代号，必须与 annotator 不同 |
| status | 见下面状态表 |
| uncertainty | 疑难位置及原因；批准时必须为空 |
| notes | 历史拼写、删改、边注、裁切或裁决说明；不混入转录正文 |

## 状态流转

| status | 含义 |
| --- | --- |
| draft | 尚未完成 |
| transcribed | 初标完成，等待独立复核 |
| uncertain | 有不确定内容，不能作为训练真值 |
| excluded | 图像/裁切/辨识条件不合格，保留记录和排除原因 |
| approved | 另一位人员已对照原图逐字确认，疑难已裁决 |

先完成约 10 个区域做一致性讨论，再扩展批量标注。存在分歧时保留初稿与讨论记录，裁决后再设 approved。不要只因为两位人员同意而把看不清的字变成确定文字。

## 文件保存

使用 UTF-8 CSV，保留表头；Excel 中先将转录、原档页码等列设为文本，防止日期、金额或长数字被自动转换。单元格内换行可以保留，另存后重新打开核对引号和换行。不要删行：需要排除的行用 excluded。标注前复制整个包为工作副本，记录人员和日期。

本次工作只形成训练/评估真值，不自动修改平台上的原文或审核状态。
